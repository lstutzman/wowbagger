### The byte-writer rewrite

Mutations used to round-trip the whole frontmatter through a YAML serializer, so
the serializer's opinions overwrote the author's: untouched fields reformatted,
nested indentation rewritten, tags dropped, comments relocated, and the
append-only `decisions` history rewritten in place.

`patch` and `transition` now locate the byte range of each field they change and
splice only those ranges, copying every other byte verbatim. Byte preservation is
true **by construction** rather than by comparison.

Verified on a hostile item — four-space nesting, `[ ]`, `[bug, stripe]`,
`{a: 1,b: 2}`, single quotes, an operator comment: patching `priority` changes
the priority line and appends a decision, and nothing else moves.

This also closed item 38 (flow-collection reformatting) and narrowed
`transition`: it used to write through a referenced anchor, and a test asserted
that as correct. It now refuses with `unsafe-yaml-mutation`. **Breaking.**

10-finding report cap (`high` sets `maxFindings: 10` — so "10 findings" measures
the cap, not the defect count; do not read it as a rate).

The product converged. Rounds 8 onward found defects almost entirely in the
**oracle and the mutation harness** — the things that measure correctness — and
roughly half were me correcting my own previous correction.

Two failure modes recurred and are worth watching for:

1. **A comment asserting a property the code beneath it did not have.** Four
   consecutive rounds. Each time the comment was written in the same breath as
   the code, describing intent rather than behaviour, and read as documentation
   rather than as a claim needing proof.
2. **Fixing the instances a report named rather than the pattern it described.**
   Three consecutive rounds, ending with a `RegExp.test` coercion hole that was
   fixed in `spec/` and left in `src/claim-request.js`, where a claim request
   with `ledger_namespace: ["wbns_…"]` was accepted.

**An open judgement call:** the last five rounds found nothing in `src/`. Their
remaining defects have the blast radius "a hypothetical third-party adapter gets
a wrong conformance verdict", and no third-party adapter exists — §10 reads
`Unverified` for every platform. Continuing to review the oracle may be lower
value than shipping. The counter-argument is that for a tool whose thesis is
harness-neutral conformance, the oracle *is* the product. Not decided.
