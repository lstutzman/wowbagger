**Authoritative facts** (do not re-derive):

- **Canonical test command:** `TMPDIR=/tmp node --test test/*.test.js`. The
  short `TMPDIR` is required — macOS caps `sockaddr_un.sun_path` at 104 bytes
  and the default temp path pushes a lock socket past it, failing
  `test/mutation-hardening.test.js` with `EINVAL`. Bare `node --test` also
  globs `test/mutation-runner.js`, a CLI runner that is not a test, and reports
  a phantom failure.
- **Node 20 lives at `/opt/homebrew/opt/node@20/bin/node`** — a Homebrew keg, so
  nvm/fnm/volta probes find nothing. Both Node 20 and Node 26 must pass.
- **Current suite: 304 tests, green on both runtimes.**
- **Never `git stash` in this repository.** Three worktrees share one stash
  stack. A concurrent session's `git reset` has also silently discarded a
  committed change here — after any push rejection, verify your own commit
  survived with `git merge-base --is-ancestor <sha> HEAD` before assuming a
  rebase fixed it.
- **`src/` must never import from `test/`.** `test/work-claim-reference.js` is
  the normative oracle and stays independent; `src/claim-request.js`
  deliberately re-implements its rules. `test/claim-request-differential.test.js`
  is what stops the two drifting — it is mutation-proven and must not be deleted.
- **The adapter conformance vectors only reproduce inside a git checkout.**
  Documented in `spec/fixtures/adapters/README.md`; a mismatch from a tarball or
  a Docker context without `.git` is an environment fault, not an adapter defect.
- **Claims are advisory and enforce nothing.** `capabilities` reports
  `mode: "advisory"` and `safe_exclusive_dispatch: false`. Nothing may change
  that without implementing fencing.

## Blockers

- **Fenced work claims carry an unresolved design question, not just unwritten
  code.** The contract requires ONE transactional coordinator serializing the
  claim decision, the clock floor, every write path, the ledger publication and
  its idempotency outcome. The ledger is Markdown files in git, so either the
  ledger bytes move inside that coordinator — which challenges the "plain
  Markdown and Git" thesis the product rests on — or the definition of fenced
  changes. Settle this with Lee before implementing. Full statement in
  `ledger/2026-08-06-fenced-work-claims-coordinator.md`.

  PropertyCompass writes its backlog from roughly twenty concurrent worktrees.
