## The thing worth knowing (unchanged, still true)

**A green conformance number on this runner has been wrong multiple times.** Do
not trust the number; trust that it can fail. Before believing any conformance
result, break something and confirm the run goes red. Item 39's D1 fix is the
latest lesson: a *weak* test passed unguarded (oversized-but-invalid JSON
refused either way); the honest test asserts the hang-prevention property that
only the real guard provides.

## Standing rules

- **`TMPDIR=/tmp` on every test command.** Without it the lock socket path
  exceeds the macOS limit. `npm run check` does not set it and fails by
  default (known one-line defect, unfiled).
- **Never `git stash` here.** Worktrees share one stash stack.
- **`spec/adapter-reference.js` is an independent oracle.** Never import it
  into `src/`; never modify it to make a vector agree with a buggy
  implementation. The one authorized exception (a *shared* confirmed defect,
  fixed in both and pinned) is recorded in `2026-08-10-project.md`.
- **`src/` imports nothing from `test/` or `spec/`.**
- **The fixtures are normative.** If a fixture fails and no contract clause
  makes it wrong, the code is wrong.
- **Coverage is judged by mutation**, not counts. Break each guard; confirm a
  test goes red (or hangs, which is also evidence — e.g. item 39's D1/D3).
- Node 20 lives at `/opt/homebrew/opt/node@20/bin/node`, not on PATH.
- `.claude/` and `.pi-subagents/` are now gitignored (local tool state);
  keep them out of commits.
- Every shipped change should first pass the four-command verification block
  at the top of this handoff.

## Ledger friction found by dogfooding (repeated here)

- **An item cannot be marked deferred/held.** No `deferred` status, no defer
  edge; `snoozed_until` is create-only. Item 22's deferral had to live in the
  handoff. **Filed as item 46.**
- **Relations cannot be edited.** `patch` accepts exactly `number` and
  `priority`; items filed with `depends_on` where `related` was correct cannot
  be fixed in-band.
- **A change of direction cannot be recorded.** Decisions attach only to
  evidence-appending edges.
- **`create` accepts an item with no `number`**, producing a handle-less item
  (re-hit when filing item 46; item 46's handle had to be `patch`ed on).
