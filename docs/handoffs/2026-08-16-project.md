## The operational lesson (learn it once)

**Every ledger mutation must be Git-committed before the next mutating
command** on a provisioned ledger. The claim store validates prior
publications at git HEAD; uncommitted work makes the next create/transition
refuse `claim-store-unavailable`/`stale-write-detected` (exit 6). The loop
that works: mutate → `git add ledger && git commit` → `claim-verify` → next.
This session practiced it ~25 times. Items #88 (document it) and #96 (failed
mutations still dirty the reconcile log) track making it humane.
