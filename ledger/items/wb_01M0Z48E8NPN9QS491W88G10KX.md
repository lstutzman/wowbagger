## Problem
During a staged commit race, auto-commit returned `git-commit-failed / failure_stage:"stage" / reason:"tree-changed"` leaving the reconcile log STAGED; 418 consecutive mutations then refused `staged-paths-present`. The documented recovery, `mutation-finalize --recovery-token`, fails with the IDENTICAL refusal — while both commit_set files hash byte-for-byte equal to the token's pins. Only the git INDEX changed, which the recovery token does not model. Item is published+committed but the tree stays unwritable except via out-of-band `git reset`.
